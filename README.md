# موقع الدكتور عبدالله اليابس للمحاماة والاستشارات القانونية

إعادة تصميم وتحريك لموقع [alyabislaw.com](https://alyabislaw.com) بموقع ثابت، بنصوصهم وخدماتهم وعملائهم كما في موقعهم الحالي،
وهوية من شعارهم: حبر أسود وذهبي العمود على ورق عاجي، وخط IBM Plex Sans Arabic.

- **المعاينة:** `alyabis.sites.alraedlaw.com` (محجوبة عن محركات البحث ما دام `PREVIEW = True`).
- **بوابة العملاء:** صفحة دخول المكتب في الرائد `https://alyabislaw.alraedlaw.com/login` (المستأجر 301)، ويحول إليها `/login` و`/admin`.

## ما فيه
- **الافتتاحية:** يبنى العمود كما في الشعار: القاعدة، فالعمودان الذهبيان، فأحجار الكتلة الكوفية من الأسفل إلى الأعلى، فالتاج.
  ثم يكتب القلم «عبدالله بن عبدالرحمن اليابس» من اليمين وتتساقط زخارفه، ثم ينتقل العمود والاسم إلى الترويسة (الشعار الأفقي).
  خطوط القلم مولدة من هيكل الحروف (`_src/logo/vectorize.py`: فروع الهيكل، وتقليم الزوائد، ومد الأطراف إلى رؤوس الحروف، ونقرات للفجوات)، والتغطية 99.8%.
- **الخدمات أعمدة:** ست ركائز كأعمدة متجاورة بتيجان وقواعد ذهبية، تقوم من قواعدها مع التمرير.
- قائد الفريق وصفاته حجارة تستقر بالتتابع، وقسم خاص لخبرة الإفلاس، وشعارات العملاء، ونموذج استشارة يكتب رسالة واتساب بنوع الخدمة ووقت التواصل.

## البناء
```bash
python _src/logo/analyze.py && python _src/logo/vectorize.py   # عند تغيير الشعار فقط
python _src/build.py
```
عند تغيير CSS أو JS ارفع `V` في `build.py`.

- نص «عمل خلالها في العديد من الدوائر القضائية» مكمل: الجملة في موقعهم تبدأ بـ«خلالها» بلا فعل.
- في شعارهم «Advocates & Legal Consultans» بلا حرف t (من الشعار نفسه، لم يعدل).
